# Changelog

## 1.0.0

- Initial release.
- Ten font families: Cairo, Tajawal, Almarai, Changa, IBM Plex Sans Arabic, Noto Kufi Arabic, Roboto, Poppins, Montserrat, Open Sans.
- 73 real TTF files in weights from Thin (100) to Black (900).
- `SaqrFonts` one-line API with size, weight, color, letter spacing and height options.
- `SaqrTextStyles` semantic styles: headline, title, subtitle, body, bodySmall, caption.
- Demo application with search, Arabic/English filter, weight showcase, comparison, light and dark themes, and copyable usage examples.
- Unit tests for the API and for the shipped font files and licenses.
