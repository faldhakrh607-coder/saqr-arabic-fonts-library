# Demo application

A Flutter demo application for the `saqr_arabic_fonts` package.

It shows all ten font families with Arabic and English sample text, lets
you search fonts by name, filter Arabic and English families, see every
weight of each family, compare two fonts side by side, switch between
light and dark themes, and copy the usage code of any font.

Run it with:

```sh
flutter run
```

Or build it for the web with:

```sh
flutter build web
```
